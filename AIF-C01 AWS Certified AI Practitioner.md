# AWS Certified AI Practitioner (AIF-C01)

**Priority:** 1 of 3 · **Level:** Foundational · **Cost:** $100 · **Duration:** 2–3 weeks

**Goal:** Foundational AI/ML/GenAI literacy on AWS. Counts toward Premier **Foundational** certified individuals. Vocabulary base for MLA-C02 and AIP-C01.

**Path:** [curriculum.md](curriculum.md) → **AIF-C01** → [MLA-C02](MLA-C02 AWS Certified Machine Learning Engineer – Associate.md) → [AIP-C01](AIP-C01 AWS Certified Generative AI Developer – Professional.md)

---

## Exam snapshot

| Item | Detail |
|---|---|
| Duration | 90 minutes |
| Format | 65 questions (multiple choice / multiple response) |
| Validity | 3 years (MLA Associate also recertifies this) |
| Delivery | Pearson VUE or online proctored |
| Official page | https://aws.amazon.com/certification/certified-ai-practitioner/ |
| Exam guide (PDF) | https://docs.aws.amazon.com/pdfs/aws-certification/latest/ai-practitioner-01/ai-practitioner-01.pdf |

### Exit criteria

Official practice exam ≥80%; can explain FM vs traditional ML, RAG, responsible AI, and core AWS AI services.

---

## Domains (weight)

1. **Fundamentals of AI and ML** — 20%
2. **Fundamentals of GenAI** — 24%
3. **Applications of Foundation Models** — 28%
4. **Guidelines for Responsible AI** — 14%
5. **Security, Compliance, and Governance for AI Solutions** — 14%

---

## Study plan

1. Read the [AIF-C01 exam guide (PDF)](https://docs.aws.amazon.com/pdfs/aws-certification/latest/ai-practitioner-01/ai-practitioner-01.pdf).
2. Complete the AWS Skill Builder **Exam Prep Plan: AWS Certified AI Practitioner**.
3. Take the official practice question set, then the official pretest; note weak domains.
4. Fill gaps with short Skill Builder modules (Bedrock intro, responsible AI, prompt engineering basics). Light Console time: Bedrock playground, simple Knowledge Base walkthrough.
5. Official practice exam → schedule when consistently ≥80%.

---

## Focus topics

- AI vs ML vs GenAI; supervised / unsupervised / reinforcement; training vs inference
- Foundation models, tokens, embeddings, context windows, hallucinations
- Prompt engineering patterns; fine-tuning vs RAG (when to use which)
- AWS AI service map at a conceptual level: Bedrock, SageMaker AI, Rekognition, Comprehend, Transcribe, Translate, Textract, Kendra, Q Business
- Responsible AI: bias, fairness, transparency, human oversight
- Security/governance: IAM least privilege, data residency, encryption, Guardrails concepts

---

## Done when

You can answer “what / why / which AWS service” questions without needing deep pipeline or agent implementation detail.

---

## Study habits for this phase

- **Official sources first:** exam guide + Skill Builder prep plan + official practice exams. Third-party dumps are a liability.
- Light Console is enough here; deep IaC/hands-on starts in MLA.
- **Booking:** Pearson VUE; schedule only after practice-exam threshold, not after “finishing the course.”
- Passing [MLA-C02](MLA-C02 AWS Certified Machine Learning Engineer – Associate.md) later auto-recertifies this cert.
