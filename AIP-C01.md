# AWS Certified Generative AI Developer – Professional (AIP-C01)

**Priority:** 3 of 3 · **Level:** Professional · **Cost:** $300 · **Duration:** 8–10 weeks

**Goal:** Production GenAI applications on AWS — FMs, RAG, agents (including Bedrock AgentCore), safety, optimization, and troubleshooting. Counts as **Technical** and toward Premier **Pro/Specialty** depth. Highest leverage for AI Competency delivery.

## Study plan

1. Read the [AIP-C01 exam guide (PDF)](https://docs.aws.amazon.com/pdfs/aws-certification/latest/ai-professional-01/ai-professional-01.pdf).
2. Skill Builder Exam Prep Plan for Generative AI Developer – Professional.
3. Build at least one production-shaped project (even if personal):
   - Bedrock FM integration with retrieval (Knowledge Bases / OpenSearch / vector store)
   - Agent with tools/gateway patterns (AgentCore where applicable)
   - Guardrails, logging, eval harness, cost/latency controls
4. Deep-read: prompt/flow management, Knowledge Bases, Agents/AgentCore, Guardrails, evaluation, IAM for agents, VPC/private access patterns.
5. Optional companion (does **not** count for partner tier): Skill Builder **AWS Agentic AI Demonstrated** microcredential for AgentCore hands-on proof.
6. Official practice exam → schedule at ≥80%.

## Focus topics

- Choosing FMs; grounding with enterprise data; chunking, embeddings, hybrid search
- Application integration patterns: sync/async APIs, streaming, event-driven GenAI
- Agents, tools, memory, identity; AgentCore Runtime / Gateway / Memory concepts
- Safety: Guardrails, PII, prompt injection, content filters, human-in-the-loop
- Cost/latency/token optimization; caching; model routing; observability
- Evals (offline/online), regression on prompts/agents, failure diagnosis
