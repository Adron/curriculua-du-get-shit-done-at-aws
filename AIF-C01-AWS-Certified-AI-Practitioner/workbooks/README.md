# AIF-C01 Workbooks

Practice packs that turn topic notes into **retrieval, judgment, and hands-on** reps. Topic docs teach; workbooks force you to use the knowledge closed-book before checking answers.

**Back to:** [Cert README](../README.md) · [Punch list](../PUNCH-LIST.md) · [Curriculum home](../../index.md)

---

## How to use each workbook

1. Skim linked `../topics/*.md` once (open-book orientation).
2. Close the notes. Complete **Activate prior knowledge** and **Retrieval practice** without peeking.
3. Work the scaffolding: **Worked example → Guided practice → Independent practice**.
4. Do **Scenario / decision** items like exam judgment calls.
5. Run the **Hands-on lab** (AWS Console) or the **paper architecture** alternate if you have no account.
6. Review **Misconceptions / exam traps**, then **Teach it back** out loud or in writing.
7. Check the **Mastery checklist**. Only then open the **Answer key** at the end.
8. Missed items → re-read the linked topic section → redo only those questions 24h later.

Do **not** scroll to the answer key first. Struggle is the point (desirable difficulty).

## Suggested 2–3 week schedule

Assume ~5–8 hrs/week. Domains 2+3 are >50% of the exam — protect that time.

| Day | Focus | Workbook | Est. time |
|---|---|---|---|

**Compress (experienced cloud + GenAI):** WB01 half-day → WB02–03 deep → WB04 skim traps → WB05 + practice exam.

**Stretch (new to GenAI):** Insert an extra day after WB02 for Bedrock playground reps before WB03.

## Learning science notes (why this shape)

| Practice | Why it is here |
|---|---|
| Observable objectives | You know when you are done |
| Activate prior knowledge | Primes schemas; reduces “blank page” on new vocab |
| Short concept refresh + topic links | Avoids re-reading walls of notes during practice |
| Closed-book retrieval | Strengthens memory more than re-reading |
| Worked → guided → independent | Fades scaffolding (cognitive load management) |
| Scenario / decision items | Matches exam judgment, not trivia |
| Hands-on / paper architecture | Dual coding + transfer to Console mental models |
| Misconceptions | Pre-bunks common distractors |
| Teach it back | Forces organization; reveals gaps |
| Mastery checklist | Exit criteria before moving on |
| Answer key at end | Protects retrieval attempts |

Spaced repetition tip: after finishing WB05, re-do only the retrieval sections of WB02 and WB03 once more before the practice exam.
