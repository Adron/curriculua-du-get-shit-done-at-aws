# AIF-C01 Workbooks

The topic docs teach. The workbooks make me **use** what I learned, closed-book, before I'm allowed to check the answers. Retrieval, judgment calls, and hands-on reps. That's where it actually sticks.

**Back to:** [Cert README](../README.md) · [Punch list](../PUNCH-LIST.md) · [Curriculum home](../../index.md)

---

## How to use each workbook

1. Skim the linked `../topics/*.md` once. Open-book, just to get oriented.
2. Close the notes. Do **Activate prior knowledge** and **Retrieval practice** without peeking.
3. Work the scaffolding: **Worked example → Guided practice → Independent practice**.
4. Treat the **Scenario / decision** items like exam judgment calls.
5. Run the **Hands-on lab** in the AWS Console, or the **paper architecture** alternate if you don't have an account handy. The labs line up with the early [build milestones](../../build.md) (B1-B3).
6. Read the **Misconceptions / exam traps**, then **Teach it back** out loud or in writing.
7. Check the **Mastery checklist**. Only then open the **Answer key** at the end.
8. Missed something? Re-read that topic section, then redo only those questions 24 hours later.

**Don't scroll to the answer key first.** The struggle is the point. (The learning science folks call it desirable difficulty. I call it doing the reps.)

## Learning science notes (why it's shaped like this)

| Practice | Why it's here |
|---|---|
| Observable objectives | So I know when I'm done |
| Activate prior knowledge | Primes what I already know; no staring at a blank page of new vocab |
| Short concept refresh + topic links | No re-reading walls of notes mid-practice |
| Closed-book retrieval | Pulling it out of your head beats re-reading, every time |
| Worked → guided → independent | Training wheels come off gradually (cognitive load management) |
| Scenario / decision items | The exam tests judgment, not trivia |
| Hands-on / paper architecture | Seeing it and doing it; transfers to Console mental models |
| Misconceptions | Knock down the common distractors before the exam throws them at me |
| Teach it back | If I can't explain it, I don't know it yet |
| Mastery checklist | Exit criteria before moving on |
| Answer key at end | Protects the retrieval attempt |

Spaced repetition tip: after WB05, redo just the retrieval sections of WB02 and WB03 one more time before the practice exam.
